# Cult UI 后台

留座中转站的 React 前端，覆盖桌面、平板和手机。最终输出为单文件 `web/index.html`，沿用本机 Node 管理服务的原有 Cookie、Host、Origin 校验与 `/api` 接口。

## 开发与交付

在项目根目录运行：

```sh
npm ci --prefix web/cult
npm run deploy --prefix web/cult
```

`deploy` 先执行 TypeScript 检查与 Vite 构建，再原子更新 `web/index.html`。已运行的管理服务刷新后立即使用新版页面，不需要停浏览、回复或晚报进程。

可单独运行 `npm run dev --prefix web/cult` 调整样式。最终验证请使用打包后的本机服务：开发代理与正式服务的 Origin 校验不同。首次部署前的入口保存在 `legacy-index.html`；旧 `web/app.js`、`features.js`、`modern.js` 和样式文件未删除。

## 功能

- 总览：两位角色的实际日配额、晚报准备计划、近期活动、待处理异常。
- 观看：关键词、模型、日期筛选，15 条分页与理解详情；手机显示两行记录卡。
- 回复：私信和公开评论记录，联系人接管，组合步骤、表情和语音卡媒体展示。
- 内容：静态/GIF 表情预览、晚报播放器、选题与连载、两位角色的独立兴趣。
- 管理：记忆、作品复盘、用量预算、配额和音色设置、待审箱、联系人偏好、守护与加密备份、官方接口诊断。

待审箱使用服务端版本和内容哈希批准：未保存修改、过期版本与需要重新渲染的媒体不能批准。设置表单保留本地草稿，刷新与轮询不会覆盖正在编辑的值。没有官方应用配置时，授权按钮保持禁用。

手机使用底部常用导航与全屏菜单；平板折叠侧栏；桌面使用分组侧栏。弹窗和选择器使用 Base UI 的键盘、焦点和 Escape 行为。移动输入为 16px，避免 iOS 聚焦时自动放大。

## Cult UI 来源

实际使用官方 Halo Button、Input/Textarea、Switch、Select、Tabs、Progress 源码与 Base Select 依赖，位于 `src/components/ui`；原始 registry JSON、下载来源与 MIT 许可保存在 `registry/`。

工作台调整：统一平面配色、去掉持续装饰动画与渐变高光、保留控件逻辑和加载反馈；统一为本产品的蓝灰数据标记与 DM Sans 字体。所有 npm 依赖均在本目录单独锁定；不修改后端根依赖。

设计方向为 Accent ladder（seed 207541166），保留现有字体和两位角色形象。两位角色的实际配额对照是总览的主要内容；没有虚构业务统计。

## 验证

- TypeScript 与生产构建通过；所有管理页面及视频详情能实际打开。
- 隔离实例端口 3158：配置修改和持久化回读、刷新保留未保存值、草稿编辑与版本批准、联系人称呼和跨午夜静默设置、备份计划弹窗均通过。
- 浏览器实际验证：空结果、分页、DeepSeek 筛选、记录详情、手机菜单、GIF 筛选和弹窗；视频播放器读取到 1080×1920、52.5 秒的现有成片，资源无错误。
- 正式后台总览在 1440×900、768×1024、390×844 通过布局检查；检查记录和截图在项目 `.taste-skill/cult-redesign/`。
- 观看页保留真实抖音昵称中的 emoji。它们属于来源数据；UI 自身的导航、标题和空态未使用 emoji 装饰。

隔离界面测试没有启动自动回复进程，也没有提交正式账号配置、评论、私信或视频。页面中的守护安装、恢复、授权与发送批准均由用户实际操作触发。

会话恢复补充：读取数据遇到 401 时，仅重新取得同源本机会话再重试读取，不重试写入操作。已使用两个本机端口验证会话失效后重新连接；测试实例使用 localhost 主机名与正式 127.0.0.1 分开。
