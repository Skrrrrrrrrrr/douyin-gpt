# Animated sticker keyframe prompts

Built-in imagegen, transparent background. The four generated keyframes are encoded as a GIF by FFmpeg without repainting the artwork.

## gpt-wave

Use case: illustration-story. Asset type: a single 2-by-2 animation keyframe SPRITE SHEET for a chat GIF. Input image is the identity and style reference for the same chibi AI host (white/lavender hair, cream horns, violet eyes, ornate purple-white outfit). Make exactly FOUR equal SQUARE cells arranged 2 columns and 2 rows, on one square canvas. Every cell has the SAME character at the SAME scale and centre with matching costume, clean pastel linework and generous transparent margins. Cell order is row-major. Animation states: top left: hand upright; top right: hand gently tilted to the left; bottom left: hand gently tilted to the right; bottom right: hand upright again. A friendly waving motion, other hand stays still. This is one continuous small animation, keep hair silhouette, face scale and all static features registered; change ONLY the described pose/expression. Large Chinese sticker text exactly "嗨" under the character in EACH of the four cells, identical lettering size and baseline across cells. White die-cut border around character and lettering. Genuinely transparent background throughout, NO grid borders, NO cell numbers, NO other text, NO other characters, NO scenery. Do not combine poses within one cell or make motion trails. Friendly, modest, nonsexual. Must remain legible as four standalone chat-sticker frames.
