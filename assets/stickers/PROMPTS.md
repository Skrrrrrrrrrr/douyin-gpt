# Chat sticker prompts

Built-in imagegen, transparent_background=true. Each source is the corresponding character in assets/hosts. Output files are original full stickers; no crop or repaint step.

## gpt-ack

Use case: illustration-story. Asset type: one square chat sticker for a personal Douyin AI assistant. The attached image is an identity and style reference only. Draw ONLY this white/lavender-haired horned GPT character with purple eyes and purple-white floral outfit, in a joyful chibi bust pose giving a clear little salute, smiling confidently, saying "收到". Exact visible Chinese text: "收到". Large simple bold hand-lettered Chinese at the bottom, perfectly legible at small chat size, white die-cut outline around character and lettering. Preserve reference hair, eyes, accessories and costume, same polished pastel anime linework. Framing: square, character head and hands fully inside a generous 8% safe margin, no other characters. Genuinely transparent background; no scenery, no black rectangle, no watermark or extra text. Friendly, modest, non-sexual, playful reaction sticker. The result is a single complete sticker, never a grid or sheet.
